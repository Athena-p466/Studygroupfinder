1. Study Group Finder:
    - Study group finder is a Spring boot web application that lets students post study groups for their courses and browse open groups. It allows students to easily create groups in order to find more help in their courses.

2. Team: Athena Yan
3. Requirements: Java 21
4. Build: ./mvnw clean project
5. Run: ./mvnw spring-boot:run
6. Access: open http://localhost:8080 in the browser
7. Setup notes: No installation or configuration is needed, just run the application
